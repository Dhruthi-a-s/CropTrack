# 🌱 CropTrack – Local Agricultural Market Price Tracker

**A web-based platform for monitoring and comparing local agricultural crop prices in Puttur and Sullia, Karnataka.**

## 📌 About the Project

CropTrack is a web-based agricultural market price tracking system designed to help farmers access and compare crop prices in their local markets.

Prices of agricultural products can vary between shops and locations. CropTrack aims to make this information easier to access by providing a platform where users can search for crop prices and view available shop-wise price reports.

## 🎯 Problem Statement

Farmers may find it difficult to obtain updated local crop prices and compare quotations from different shops. Lack of accessible price information can make it challenging to identify suitable selling opportunities.

## 💡 Proposed Solution

CropTrack provides a centralized website where users can:

- Select an agricultural crop.
- Choose a location such as Puttur or Sullia.
- Search for available price reports.
- View submitted shop-wise prices.
- Compare available price quotations.
- Explore historical price trends as the system develops.

## ⚙️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/CropTrack.git
   ```

2. Open the project folder:

   ```bash
   cd CropTrack
   ```

3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the Flask application:

   ```bash
   python app.py
   ```

5. Open the local website in your browser at:

   `http://127.0.0.1:5000`
